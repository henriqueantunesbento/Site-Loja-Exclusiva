## **Introdução:** 

Este é um trabalho de desenvolvimento de um site para a web com 10 páginas HTML destinado a matéria de front-end para a web, o grupo escolheu como organização
uma loja de roupas chamada de "Loja exclusiva", a escolha foi feita pois essa loja é pertencente a uma pessoa próxima a um dos integrantes do grupo, sendo então
mais fácil de se comunicar com a representante da empresa e assim coletar requisitos. O objetivo do site é fornecer um meio pelo qual o cliente consegue mais
acesso a loja sem a necessidade de ir presencialmente, além de ser capaz de visualizar preços e ofertas oferecidas pela organização, facilitando a comunicação
e auxiliando o comércio a aumentar suas vendas e proximidade com clientes.

## **Relato de como foi feita a entrevista/visita à organização real**.

A entrevista teve como objetivo coletar informações para o desenvolvimento de um site para uma loja. A entrevistada foi a proprietária, que já era conhecida pelo entrevistador. A entrevista foi realizada presencialmente na loja, no dia 03/08/2026, com duração de aproximadamente 30 minutos. Foram coletadas informações sobre a loja, seus produtos, serviços e conteúdos necessários para a criação do site. A entrevista ajudou a compreender as necessidades da loja e forneceu informações importantes para o desenvolvimento do projeto de Front-End.

# **Explicação do processo de desenvolvimento do site em si:**

Antes de começarmos o desenvolvimento do site, separamos com a ajuda da inteligência artificial "Gemini" perguntas que seriam realizadas na entrevista para
levantamento de requisitos. Com isso, foi feita a entrevista presencialmente com a dona da loja "exclusiva" e assim, coletados os requisitos para o desenvolvimento
do site. Tendo então os dados necessários, em sala de aula escolhemos as páginas e a organização das pastas do projeto, separando também a responsabilidade 
de cada integrante do grupo, estabelecemos também um padrão de cabeçalho e rodapé seguido em todas as páginas do site para facilitar a navegação pela página.
Os membros da equipe ao desenvolverem as páginas lançavam elas no github em branchs separadas da main, ao final do desenvolvimento utilizamos do W3C Validator
para verificar possíveis erros nas páginas, tinha 1 erro e alguns avisos, concertados os erros e avisos juntamos tudo na main, sendo a versão final do projeto
e que foi hospedada via github pages.

## **Conclusão:**

No começo do desenvolvimento o grupo estava um tanto perdido sobre como iria ser desenvolvido o site em HTML porém, conforme fomos nos organizando e desenvolvendo o projeto entendemos como criar o site, aprendendo coisas como a estrutura HTML, como trabalhar encima de requisitos fornecidos e não apenas de dados inventados.
